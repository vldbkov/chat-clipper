ChatClipper — ユーザーガイド

Copyright (©) 2026, Vladimir Baykov. All rights reserved.

ChatClipper は、AI アシスタント（DeepSeek、ChatGPT、Qwen、GLM など）とのチャットを、1 つの整然とした Word ファイルに記録するのに役立つ小さな Windows ユーティリティです。手動でコピー＆ペーストする必要はもうありません。アプリが代わりに行います。

特長

  • 必要なものだけを保存できます。選択した返信、重要な断片、コード スニペットなどであり、対話ツリー全体ではありません。
  • 手動のコピー＆ペーストは不要です。ブラウザーで「コピー」を 1 回クリックするだけで、テキストはすでに Word ファイルにあります。
  • 各プロジェクトは個別のファイルなので、1 つのドキュメントには 1 つのトピックだけが入ります。
  • 書式は保持されます。見出し、リスト、太字、コード。
  • バックグラウンドで静かに動作し、システムを遅くしません。
  • インターフェイスは 5 言語で利用できます。

対象ユーザー

AI チャット ツールを頻繁に使い、履歴を残したい人: 開発者、アナリスト、ライター、研究者、学生。

インストール

最も簡単な方法はインストーラーを実行することです。

  1. GitHub の最新リリース ページから chatclipper-setup.exe をダウンロードします。
  2. ダブルクリックし、インストーラーの指示に従います。
  3. インストール後、ChatClipper コントロール パネル — ボタンがある小さなウィンドウ — が画面の右下隅に表示されます。

Python やその他のソフトウェアは不要です。すべて同梱されています。

初回起動

インストールして起動すると、コントロール パネルが表示されます。これが既定のアプリのメイン ウィンドウです。

パネルには 5 つのボタンがあります:

  • ステータス — ステータス ウィンドウを表示します（現在のメイン プロジェクトとアクティブなプロジェクトの一覧）。
  • 設定 — 設定ウィンドウを開きます。
  • 元に戻す — 最後の書き込みを元に戻し、別のプロジェクトに移動します。
  • 開始 / 一時停止 — クリップボードの追跡を有効または一時停止します。
  • 終了 — ChatClipper を閉じます。シングル クリックで終了、ダブル クリックで再起動します。

パネルはマウスで画面上の任意の場所にドラッグできます。アプリはその位置を記憶し、次回そこに開きます。

設定ウィンドウ

設定ボタンで開きます。ここでプロジェクトと動作を定義します。

上部にプロジェクトの一覧があります。各プロジェクトについて、名前、フォルダー、ファイルが表示されます。

一覧の下にプロジェクト ボタンがあります:

  • 追加 — 新しいプロジェクトを追加します。名前、フォルダー、ファイル名を入力するダイアログが開きます。形式（Word、Markdown、プレーン テキスト）も選択できます。
  • 編集 — 選択したプロジェクトを変更します。
  • 削除 — プロジェクトを削除します。
  • メインに設定 — 選択したプロジェクトをメインにします。既定では書き込みはそこに送られます。
  • アクティブ切替 — プロジェクトを有効または無効にします。無効なプロジェクトはコピー ポップアップに表示されません。

一覧の下の行に、メイン プロジェクトとアクティブなプロジェクトが表示されます。

次にオプションがあります:

  • 最小テキスト長 (文字) — コピーされたテキストの最小長。短すぎる断片（既定では 35 文字未満）は無視されます。
  • ポップアップ時間 (秒) — プロジェクト ピッカーが自動で閉じるまで画面に表示される時間。
  • ウィンドウの透明度 (%) — プロジェクト ピッカーの透明度。
  • 自動起動 — Windows と一緒に ChatClipper を起動します。
  • トレイを表示 — パネルの代わりにトレイ アイコンに切り替えます（以下の「トレイ」セクションを参照）。
  • Pandoc — Markdown を Word に変換するために Pandoc を使用します（インストールされている場合）。
  • ソース — コピー元: Chrome または別のアプリ。
  • サウンド — コピーを待つ間に再生されるカチッという音。「...」をクリックして利用可能なサウンドから選択します。
  • 言語 — インターフェイス言語。

下部に保存とキャンセルがあります。何かを変更してウィンドウを閉じると、ChatClipper は保存するかどうかを尋ねます。

ステータス ウィンドウ

ステータスボタンで開きます（または起動時に自動的に表示されます）。現在の状態を表示します。

  • タイトルは、書き込み先のメイン プロジェクトの名前です。
  • アクティブなプロジェクトの一覧 — 最大 9 項目。
  • いずれかをクリックすると、それがメイン プロジェクトになります。以降のすべての書き込みはそこに送られます。
  • アプリが一時停止しているときは、赤い PAUSE スタンプがウィンドウの上に表示されます。

ウィンドウはドラッグできます。そのままにしておくと、数秒後に自動的に閉じます。

使用方法

  1. 設定を開き、少なくとも 1 つのプロジェクトを追加します: 名前、フォルダー、ファイル。たとえば、プロジェクト「DeepSeek」、ファイル「deepseek-chat.docx」。
  2. それをメインに設定します（メインに設定）。
  3. Chrome で AI チャットを開きます。
  4. 断片を選択して Ctrl+C を押します（またはチャット UI の「コピー」をクリックします）。
  5. 1 秒後にプロジェクト選択のポップアップが表示されます。希望するものをクリックするか、自動的に閉じるまで待ちます（メイン プロジェクトが使用されます）。
  6. Word ファイルを開くと、テキストがあります（書き込みは約 5 秒遅延します）。

インターフェイス言語

既定では、インターフェイスは英語です。ロシア語、ドイツ語、スペイン語、日本語に切り替えるには:

  1. 設定 → 言語 → 言語を選択します。
  2. 保存をクリックします。アプリを再起動するか尋ねるダイアログが表示されるので、確認します。
  3. 再起動後、インターフェイスは選択した言語になります。

初回起動時、ChatClipper は Windows のロケールに合わせようとします。言語が利用できない場合は、英語が使用されます。

トレイ

パネルの代わりに ChatClipper をシステム トレイ（時計の近く）に置いておきたい場合:

  1. 設定 → トレイを表示 → チェックボックスをオンにします。
  2. 保存をクリックし、再起動を確認します。
  3. 再起動後、パネルの代わりにトレイ アイコンが表示されます。

アイコンを右クリックしてメニューを開きます: ステータス、設定、元に戻す、一時停止、再起動、終了。

パネルに戻るには、設定でトレイを表示のチェックを外します。

知っておくとよいこと

  • 書き込みはパフォーマンス上の理由により約 5 秒遅延します。
  • Word ファイルがエディターで開かれている場合、新しい内容はすぐには反映されません。ファイルを閉じて再度開いてください。
  • 書き込みと元に戻すの間にファイルを手動で編集しないでください。そうしないと、元に戻すで誤った段落が削除されます。
  • アプリはインターネットに接続せず、データを送信しません。

よくある質問

何か支払う必要がありますか？
いいえ。ChatClipper は無料で、MIT ライセンスの下で配布されています。

メモはどこに保存されますか？
プロジェクト作成時に指定した場所です。既定では、プロジェクト フォルダー内です。

複数のチャットを同時に保持できますか？
はい。各プロジェクトは個別のファイルです。設定、ステータス ウィンドウ、またはポップアップでプロジェクトを切り替えます。

誤ってファイルを削除してしまった場合は？
プロジェクトをもう一度作成してください。同じファイル名とフォルダーを使用すると、ChatClipper は引き続きそこに書き込みます。

アンインストールするには？
Windows の「アプリと機能」から行います。設定とプロジェクト ファイルは別途手動で削除します。それらはアプリ フォルダーの外にあります。

バックグラウンドで実行しても安全ですか？
はい。ChatClipper はインターネットに接続せず、どこにもデータを送信せず、コピーの瞬間にクリップボード以外は何も読み取りません。
