ChatClipper — Benutzerhandbuch

Copyright (©) 2026, Vladimir Baykov. All rights reserved.

ChatClipper ist ein kleines Windows-Programm, mit dem Sie Ihre Chats mit KI-Assistenten (DeepSeek, ChatGPT, Qwen, GLM und ähnliche) in einer einzigen Word-Datei festhalten können. Kein manuelles Kopieren und Einfügen mehr — das Programm erledigt das für Sie.

Vorteile

  • Sie speichern nur das, was Sie brauchen: einzelne Antworten, wichtige Fragmente, Codebeispiele — nicht den gesamten Gesprächsverlauf.
  • Kein manuelles Kopieren und Einfügen: ein Klick auf "Kopieren" im Browser — und der Text steht in Ihrer Word-Datei.
  • Jedes Projekt ist eine eigene Datei — so enthält ein Dokument nur ein Thema.
  • Formatierung bleibt erhalten: Überschriften, Listen, Fett, Code.
  • Läuft leise im Hintergrund — bremst das System nicht aus.
  • Oberfläche in 5 Sprachen verfügbar.

Für wen ist das gedacht

Für alle, die viel mit KI-Chats arbeiten und den Verlauf behalten möchten: Entwickler, Analysten, Autoren, Forscher, Studierende.

Installation

Der einfachste Weg ist der Installer.

  1. Laden Sie chatclipper-setup.exe von der letzten Release-Seite auf GitHub herunter.
  2. Doppelklicken Sie darauf und folgen Sie den Anweisungen.
  3. Nach der Installation erscheint in der rechten unteren Ecke das Bedienfeld von ChatClipper — ein kleines Fenster mit Schaltflächen.

Python oder andere Programme sind nicht nötig — alles ist enthalten.

Erster Start

Nach dem ersten Start sehen Sie das Bedienfeld — das ist das Hauptfenster des Programms.

Beim allerersten Start legt ChatClipper automatisch ein Projekt Default im Ordner ~/ChatClipper (Benutzer-Home) mit einer leeren Word-Datei an, die bereits eine Überschrift enthält. Sie können sofort mit dem Kopieren beginnen — keine Konfiguration nötig.

Außerdem hören Sie ein leises Ticken einer Uhr. Das bedeutet, dass das Programm läuft und darauf wartet, dass Sie etwas aus einem Chat kopieren. Der Ton verstummt bei Pause und kehrt beim nächsten Start zurück.

Das Bedienfeld hat fünf Schaltflächen:

  • Status — Statusfenster anzeigen (aktuelles Hauptprojekt und Liste aktiver Projekte).
  • Einstellungen — Einstellungsfenster öffnen.
  • Rückgängig — letzten Eintrag rückgängig machen und in ein anderes Projekt verschieben.
  • Start / Pause — Zwischenablage-Überwachung ein- oder ausschalten.
  • Beenden — ChatClipper schließen. Einzelklick beendet, Doppelklick startet neu.

Das Bedienfeld lässt sich mit der Maus verschieben. Die Position wird gespeichert und beim nächsten Start wiederverwendet.

Einstellungsfenster

Wird über die Schaltfläche Einstellungen geöffnet. Hier werden Projekte und Verhalten festgelegt. Das Fenster ist modal: solange es offen ist, reagieren andere Fenster und das Bedienfeld nicht.

Oben sehen Sie die Liste Ihrer Projekte: Name, Ordner und Datei.

Unter der Liste befinden sich die Projekt-Schaltflächen:

  • Hinzufügen — neues Projekt anlegen. Ein Dialog fragt nach Name, Ordner und Dateiname. Das Format (Word, Markdown, reiner Text) ist wählbar.
  • Bearbeiten — ausgewähltes Projekt ändern.
  • Löschen — Projekt entfernen.
  • Als Haupt setzen — das ausgewählte Projekt zum Hauptprojekt machen. Einträge gehen standardmäßig dorthin.
  • Aktiv umschalten — Projekt ein- oder ausschalten. Inaktive Projekte erscheinen nicht im Auswahlfenster beim Kopieren.

Die Zeile unter der Liste zeigt das Hauptprojekt und die aktiven Projekte.

Danach folgen die Optionen:

  • Min. Textlänge (Zeichen) — Mindestlänge des kopierten Textes. Zu kurze Fragmente (standardmäßig weniger als 35 Zeichen) werden ignoriert.
  • Popup-Zeit (Sek.) — wie lange die Projektauswahl angezeigt wird, bevor sie sich automatisch schließt.
  • Deckkraft des Statusfensters (%) — Deckkraft von Statusfenster und Projektauswahl (30–100, Schritt 10).
  • Thema — die Schaltfläche ☀ / 🌙 im Kopfbereich wechselt zwischen hellem und dunklem Thema. Gilt für alle Fenster und das App-Symbol.
  • Nach Updates suchen — manuelle Prüfung gegen GitHub Releases. Beim Start läuft zusätzlich eine Hintergrundprüfung.
  • Autostart — ChatClipper zusammen mit Windows starten.
  • Tray anzeigen — stattdessen ein Tray-Symbol verwenden (siehe Abschnitt "Tray" unten).
  • Pandoc — Pandoc verwenden, um Markdown in Word umzuwandeln (falls installiert).
  • Quelle — Quelle des Kopierens: Browser (Chrome, Opera, Edge, Brave, Vivaldi und andere Chromium-basierte Browser).
  • Ton — Ticken im Wartemodus. Klicken Sie auf "...", um einen Ton auszuwählen.
  • Sprache — Sprache der Oberfläche.

Unten befinden sich Speichern und Abbrechen. Wenn Sie etwas geändert und das Fenster geschlossen haben, fragt ChatClipper, ob gespeichert werden soll.

Statusfenster

Wird über Status geöffnet (oder beim Start automatisch angezeigt). Zeigt den aktuellen Zustand.

  • Der Titel ist der Name des Hauptprojekts, in das geschrieben wird.
  • Die Liste der aktiven Projekte — maximal 9 Einträge.
  • Ein Klick auf einen Eintrag macht ihn zum Hauptprojekt — alle weiteren Einträge gehen dorthin.
  • Wenn das Programm pausiert ist, erscheint ein rotes PAUSE-Siegel über dem Fenster.
  • Einzelklick auf das PAUSE-Siegel hebt die Pause auf und setzt die Überwachung fort.

Das Fenster ist verschiebbar. Wird es nicht berührt, schließt es sich nach einigen Sekunden automatisch.

Bedienung

  1. Öffnen Sie einen KI-Chat (DeepSeek, ChatGPT, Qwen, GLM und ähnliche) in einem Chromium-basierten Browser (Chrome, Opera, Edge, Brave, Vivaldi).
  2. Kopieren Sie die Antwort auf eine von zwei Arten:
    • Klicken Sie die Schaltfläche Kopieren in der Chat-Oberfläche (empfohlen — so bleibt die HTML-Formatierung erhalten), oder
    • markieren Sie den Text und drücken Sie Strg+C.
  3. Nach einer Sekunde erscheint die Projektauswahl — klicken Sie darauf oder warten Sie (das Hauptprojekt wird verwendet).
  4. Öffnen Sie die Word-Datei — der Text steht bereits darin (Verzögerung etwa 5 Sekunden).
  5. Weitere Projekte: Einstellungen → Hinzufügen, Name, Ordner und Datei angeben. Ein Projekt als Hauptprojekt festlegen (Als Haupt setzen) — dorthin gehen die Schreibvorgänge standardmäßig.

Sprache der Oberfläche

Standardmäßig ist die Oberfläche auf Englisch. Um sie auf Russisch, Deutsch, Spanisch oder Japanisch umzustellen:

  1. Einstellungen → Sprache → gewünschte Sprache wählen.
  2. Klicken Sie auf Speichern. Ein Dialog fragt nach einem Neustart — bestätigen.
  3. Nach dem Neustart ist die Oberfläche in der gewählten Sprache.

Beim ersten Start versucht ChatClipper, die Windows-Sprache zu übernehmen. Ist sie nicht verfügbar, wird Englisch verwendet.

Tray

Wenn Sie ChatClipper lieber im System-Tray (neben der Uhr) statt auf dem Bedienfeld haben möchten:

  1. Einstellungen → Tray anzeigen → Häkchen setzen.
  2. Auf Speichern klicken und den Neustart bestätigen.
  3. Nach dem Neustart erscheint statt des Bedienfelds ein Tray-Symbol.

Rechtsklick auf das Symbol öffnet das Menü: Status, Einstellungen, Rückgängig, Pause, Neustart, Beenden.

Um zum Bedienfeld zurückzukehren — Häkchen bei Tray anzeigen in den Einstellungen entfernen.

Gut zu wissen

  • Das Ticken bedeutet, dass das Programm läuft und auf einen Kopiervorgang wartet. Abschalten: Einstellungen → Häkchen bei Sound entfernen.
  • Beim ersten Start werden automatisch ein Default-Projekt und eine leere Datei mit Überschrift im Ordner ~/ChatClipper angelegt.
  • Einträge werden mit etwa 5 Sekunden Verzögerung geschrieben — aus Performance-Gründen.
  • Wenn die Word-Datei in einem Editor geöffnet ist, erscheinen neue Inhalte nicht sofort — Datei schließen und neu öffnen.
  • Bearbeiten Sie die Datei nicht von Hand zwischen Schreiben und Rückgängig machen — sonst entfernt "Rückgängig" die falschen Absätze.
  • Das Programm verbindet sich nicht mit dem Internet und sendet keine Daten.

Häufige Fragen

Muss ich etwas bezahlen?
Nein. ChatClipper ist kostenlos und steht unter der MIT-Lizenz.

Wo werden die Notizen gespeichert?
Dort, wo Sie es beim Anlegen des Projekts angegeben haben. Standardmäßig im Projektordner.

Kann ich mehrere Chats gleichzeitig führen?
Ja. Jedes Projekt ist eine separate Datei. Das Umschalten erfolgt in den Einstellungen, im Statusfenster oder über die Auswahl beim Kopieren.

Was, wenn ich die Datei versehentlich gelöscht habe?
Legen Sie das Projekt erneut an — mit demselben Dateinamen und Ordner; ChatClipper schreibt weiter hinein.

Wie deinstalliere ich das Programm?
Über "Apps & Features" in Windows. Einstellungen und Projektdateien werden separat manuell entfernt — sie liegen außerhalb des Programmordners.

Ist der Hintergrundbetrieb sicher?
Ja. ChatClipper verbindet sich nicht mit dem Internet, sendet keine Daten und liest außer der Zwischenablage im Moment des Kopierens nichts.
