**Русский** · [English](../README.md) · [Deutsch](README-de.md) · [Español](README-es.md) · [日本語](README-ja.md)

Настольная утилита, которая следит за буфером обмена после одного клика ЛКМ в
Chrome (кнопка «Копировать» в веб-чатах, например DeepSeek) и добавляет текст в
файл .docx / .md / .txt выбранного проекта.
Работает на Windows; поддержка Linux / WSL / macOS экспериментальная.

---

## 📋 О программе

ChatClipper — лёгкая утилита, которая автоматически сохраняет ваши чаты
с ИИ-ассистентами (DeepSeek, ChatGPT и подобными) в один файл проекта.
Больше не нужно вручную копировать и вставлять — программа делает это за вас.

- Следит за буфером обмена и определяет «Копировать» в веб-чатах.
- Добавляет скопированный текст в файл проекта (.docx / .md / .txt).
- Поддерживает несколько проектов с одним основным.
- Работает в фоне — живёт в системном трее.
- При первом запуске создаёт проект Default в `~/ChatClipper` с пустым
  файлом, в котором уже есть заголовок — можно сразу копировать.
- Пока программа ждёт копирования, слышно тиканье часов — это значит,
  что программа работает и готова.

## ✨ Возможности

- Наблюдатель буфера обмена по клику ЛКМ в Chrome
- Добавление текста в файлы проектов: docx, md, txt
- Разбор Markdown (mistune): заголовки, полужирный, курсив, встроенный код,
  блоки кода, списки, цитаты, таблицы
- Необязательный конвертер Pandoc (при сбое — откат к mistune)
- Отметка времени и разделительная линия перед каждым блоком
- Несколько проектов с одним основным; формат задаётся для каждого проекта
- Всплывающее окно выбора проекта (прозрачность и длительность настраиваются)
- Клик по неосновному проекту во всплывающем окне без уведомления делает его основным
- Всплывающее окно статуса при запуске; отметка PAUSE при паузе
- Подавление дубликатов через кольцо CRC32 (5 последних значений)
- Отмена последней записи: удаляет её из исходного .docx и переносит в другой
  проект; учитывает undo_max_text_len и skip_secrets
- Буферизованная запись .docx: сброс каждые 5 с или при выходе
- Очередь ожидания, когда целевой файл занят
- Проверка потери содержимого (loss_threshold_pct + loss_min_abs_chars)
- IPC: именованный канал в Windows, Unix-сокет в POSIX, с токен-аутентификацией
- Значок в трее (Windows) или панель управления Tk (Linux / WSL / macOS)
- Автозапуск (по умолчанию выключен)
- Трей включён (по умолчанию выключен; только Windows)
- Защита от второго экземпляра (мьютекс / файловая блокировка)
- i18n: английский, русский, немецкий, испанский, японский
- Автоопределение по локали ОС при первом запуске
- Добавление нового языка: просто положите `locales/<code>.json` с `"lang.name"`
- Значок окна: chatclipper-light.ico

## ⚙️ Требования
- Windows 10/11 (Linux / macOS — экспериментально)
- Python 3.10+
- LibreOffice или MS Word для редактирования .docx
- Chrome как источник буфера обмена
- Необязательно: Pandoc в PATH для Markdown → docx

## 🚀 Установка

### Рекомендуется: виртуальное окружение uv
```
    git clone https://github.com/vldbkov/chat-clipper.git
    cd chat-clipper
    uv venv
    uv pip install -r requirements.txt
    uv run python main.py
```
### Альтернатива: pip
```
    git clone https://github.com/vldbkov/chat-clipper.git
    cd chat-clipper
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    python main.py
```
### Проще всего для конечных пользователей: установщик Windows

Скачайте `chatclipper-setup.exe` из последнего релиза и запустите его.
Python устанавливать не нужно.
После установки появляется значок в трее (Windows).

## 🎮 Использование

При первом запуске ChatClipper сам создаёт проект Default в папке
`~/ChatClipper` (домашняя папка пользователя) с пустым файлом Word,
в котором уже есть заголовок. Настройка не требуется — можно сразу копировать.

1. Откройте чат с ИИ (DeepSeek, ChatGPT, Qwen, GLM и подобные) в Chrome.
2. Скопируйте ответ одним из двух способов:
   - нажмите кнопку **Копировать** в интерфейсе чата (рекомендуется —
     так сохраняется HTML-форматирование), или
   - выделите текст и нажмите **Ctrl+C** на клавиатуре.
3. Через секунду появится всплывающее окно с выбором проекта — щёлкните
   нужный, либо дождитесь автозакрытия (сработает основной).
4. Откройте файл проекта в Word — текст уже там (запись идёт с задержкой
   около 5 секунд).
5. Чтобы добавить другие проекты: панель ChatClipper → **Настройки** → **Add**.
   Один проект сделайте основным — записи по умолчанию идут в него.

## 🧩 Структура проекта

У каждого проекта есть имя, папка, имя файла и формат
(docx / md / txt). Имя файла по умолчанию — `<ProjectName>-chat.<fmt>`.
Один проект является основным — записи по умолчанию идут туда.
Основной проект можно переключить из всплывающего окна, из окна статуса
или из окна настроек.

---

## ⚠️ Важно: буферизованная запись

После копирования целевой файл обновляется не сразу: изменения
буферизуются и сбрасываются примерно каждые 5 секунд или при выходе из приложения. Если
файл открыт в Word / LibreOffice, он не отобразит новое содержимое
на лету — закройте и откройте его заново, чтобы увидеть новые записи.

---

## ⚠️ Важно: не редактируйте .docx вручную

ChatClipper запоминает, сколько абзацев он добавил при последней записи,
и при отмене удаляет ровно столько же. Если вы вручную добавите, удалите или
измените абзацы в конце файла после записи, отмена удалит последние абзацы
по количеству, а не те, которые записала утилита.
Возможные последствия:

- Ваш ручной текст исчезнет — утилита посчитает его своим.
- Часть записи утилиты останется в файле.

Правило: если нужна отмена — не трогайте .docx между записью и отменой.
Если вы всё же отредактировали его вручную, пропустите отмену и скопируйте текст заново.

## 🌍 Платформы

- **Windows 10/11** — значок в трее, автозапуск через реестр, IPC через именованный канал.
- **Linux / WSL / macOS** — экспериментально: панель управления Tk, IPC через Unix-сокет.

## 🌐 Добавление нового языка

1. Создайте `locales/<code>.json` с теми же ключами, что и `locales/en.json`.
2. Добавьте `"lang.name": "<NativeName>"` — выпадающий список настроек и
   автоопределение по локали ОС читают его из файла.
3. Изменения кода или конфигурации не требуются.

## 🐛 Устранение неполадок

| Проблема | Решение |
|---------|----------|
| Текст не сохраняется | Нажмите кнопку **Копировать** в чате или выделите текст и нажмите **Ctrl+C**; убедитесь, что Chrome — активное окно |
| Мешает тиканье | Отключите в Настройки → Sound, либо выберите более тихий .wav |
| Файл не обновляется | Подождите ~5 с или закройте и откройте файл (буферизованная запись) |
| Значок в трее не виден | Проверьте настройки трея Windows; убедитесь, что ChatClipper запущен |
| Отмена удалила не тот текст | Не редактируйте .docx вручную между записью и отменой |
| Язык не определился | Установите язык вручную в настройках |
