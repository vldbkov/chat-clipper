ChatClipper — руководство пользователя

Copyright (©) 2026, Vladimir Baykov. All rights reserved.

ChatClipper — это небольшая программа для Windows, которая помогает вести записи чатов с нейросетями (DeepSeek, ChatGPT, Qwen, GLM и другими) в один аккуратный файл Word. Больше не нужно вручную копировать и вставлять сообщения — программа делает это за вас.

Преимущества

  • Вы сохраняете только то, что нужно: отдельные ответы, ключевые фрагменты, примеры кода — а не всю ветку диалога целиком.
  • Никакого ручного копирования и вставки: одно нажатие «Копировать» в браузере — и текст уже в вашем файле Word.
  • Каждый проект — отдельный файл, поэтому в одном документе живёт только нужная вам тема.
  • Сохраняется форматирование: заголовки, списки, жирный, код.
  • Работает тихо в фоне, не мешает и не тормозит систему.
  • Поддерживает 5 языков интерфейса.

Для кого это

Для всех, кто часто работает с чатами нейросетей и хочет сохранять историю: разработчики, аналитики, авторы, исследователи, студенты.

Как установить

Самый простой способ — запустить установщик.

  1. Скачайте файл chatclipper-setup.exe со страницы последнего релиза на GitHub.
  2. Дважды щёлкните по нему и следуйте подсказкам установщика.
  3. После установки в правом нижнем углу экрана появится панель управления ChatClipper — небольшое окно с кнопками.

Python и другие программы устанавливать не нужно — всё внутри.

Первый запуск

После установки и запуска вы увидите панель управления — это основное окно программы по умолчанию.

При самом первом запуске ChatClipper автоматически создаёт проект Default в папке ~/ChatClipper (домашняя папка пользователя) с пустым файлом Word, в котором уже есть заголовок. Можно сразу начинать копирование — настройка не требуется.

Вы также услышите тихое тиканье часов. Это значит, что программа работает и ждёт, когда вы что-нибудь скопируете из чата. Звук стихает, когда программа на паузе, и возобновляется при следующем запуске.

На панели пять кнопок:

  • Status — показать окно статуса (текущий основной проект и список активных проектов).
  • Settings — открыть окно настроек.
  • Undo — отменить последнюю запись и перенести её в другой проект.
  • Start / Pause — включить или приостановить отслеживание копирования.
  • Exit — закрыть ChatClipper. Одиночный клик — выход, двойной клик — перезапуск программы.

Панель можно перетаскивать мышью в любое место экрана. Программа запомнит позицию и в следующий раз откроется там же.

Окно настроек

Открывается кнопкой Settings. Здесь задаются проекты и параметры работы.

Сверху — список ваших проектов. Для каждого видно: имя, папку и файл.

Под списком — кнопки управления проектами:

  • Add — добавить новый проект. Откроется диалог, в котором указываются имя, папка и имя файла. Формат можно выбрать (Word, Markdown, простой текст).
  • Edit — изменить выбранный проект.
  • Delete — удалить проект.
  • Set as main — сделать выбранный проект основным. Записи по умолчанию идут именно в него.
  • Toggle active — включить или выключить проект. Неактивные проекты не показываются в окне выбора при копировании.

Строка под списком показывает основной и активные проекты.

Далее — параметры работы:

  • Min. text length (chars) — минимальная длина скопированного текста. Слишком короткие фрагменты (по умолчанию меньше 35 символов) игнорируются.
  • Popup time (sec) — сколько секунд показывается окно выбора проекта перед автозакрытием.
  • Window transparency (%) — прозрачность окна выбора проекта.
  • Autostart — запускать ChatClipper вместе с Windows.
  • Show tray — переключиться на иконку в системном трее вместо панели (см. раздел «Трей» ниже).
  • Pandoc — использовать Pandoc для конвертации Markdown в Word (если установлен).
  • Source — источник копирования: Chrome или другое приложение.
  • Sound — звук тиканья, который играет, пока программа ждёт копирования. По нажатию «...» открывается список доступных звуков.
  • Language — язык интерфейса.

Внизу — кнопки Save и Cancel. Если вы что-то изменили и закрыли окно, ChatClipper спросит, сохранить ли изменения.

Окно статуса

Открывается кнопкой Status (или автоматически при старте программы). Показывает текущее состояние.

  • Заголовок — название основного проекта, в который идут записи.
  • Список активных проектов — максимум 9 штук.
  • Щелчок по любому из них делает его основным — все последующие записи пойдут в него.
  • Если программа на паузе, поверх окна появляется красная метка PAUSE.

Окно можно перетаскивать. Если не трогать — оно автоматически закроется через несколько секунд.

Как пользоваться

  1. Откройте чат с нейросетью (DeepSeek, ChatGPT, Qwen, GLM и подобные) в Chrome.
  2. Скопируйте ответ одним из двух способов:
    • Нажмите кнопку Копировать в интерфейсе чата (рекомендуется — так сохраняется HTML-форматирование), или
    • Выделите текст и нажмите Ctrl+C на клавиатуре.
  3. Через секунду появится всплывающее окно с выбором проекта — щёлкните нужный, либо дождитесь автозакрытия (сработает основной).
  4. Откройте файл Word — текст уже там (запись идёт с небольшой задержкой около 5 секунд).
  5. Чтобы добавить другие проекты: Settings → Add, укажите имя, папку и файл. Один проект сделайте основным (Set as main) — записи по умолчанию идут в него.

Язык интерфейса

По умолчанию интерфейс ChatClipper на английском языке. Чтобы переключить его на русский, немецкий, испанский или японский:

  1. Settings → Language → выберите нужный язык.
  2. Нажмите Save. Появится окно с предложением перезапустить программу — подтвердите.
  3. После перезапуска интерфейс будет на выбранном языке.

При первом запуске ChatClipper сам пытается подобрать язык по настройкам Windows. Если такого языка в программе нет — включается английский.

Трей

Если вам удобнее держать ChatClipper в системном трее (рядом с часами), а не на панели:

  1. Settings → Show tray → поставьте галочку.
  2. Нажмите Save, подтвердите перезапуск.
  3. После перезапуска вместо панели появится значок ChatClipper в трее.

Щелчок правой кнопкой мыши по значку открывает меню: Status, Settings, Undo, Pause, Restart, Exit.

Чтобы вернуться к панели — снимите галочку Show tray в настройках.

Полезно знать

  • Тиканье означает, что программа работает и ждёт копирования. Отключить: Settings → снимите галочку Sound.
  • При первом запуске автоматически создаётся проект Default и пустой файл с заголовком в папке ~/ChatClipper.
  • Запись в файл идёт с небольшой задержкой (около 5 секунд) — это для того, чтобы программа работала быстро и не тормозила систему.
  • Если файл Word открыт в редакторе, новые записи не появятся на экране сразу — закройте и откройте файл заново.
  • Не редактируйте файл вручную между записью и отменой — иначе кнопка «Отменить» уберёт не то, что нужно.
  • Программа не выходит в интернет и не отправляет никаких данных.

Частые вопросы

Нужно ли покупать что-то ещё?
Нет. ChatClipper бесплатный, распространяется по лицензии MIT.

Куда сохраняются записи?
Туда, куда вы указали при создании проекта. По умолчанию — в папку проекта.

Можно ли вести несколько чатов одновременно?
Да. Каждый проект — отдельный файл. Переключать проекты можно в настройках, в окне статуса или через всплывающее окно.

Что если я случайно удалил файл?
Создайте проект заново — имя файла и папку можно указать те же, ChatClipper продолжит писать в него.

Как удалить программу?
Через «Установка и удаление программ» Windows (или «Приложения → Установленные приложения»). Настройки и файлы проектов удаляются отдельно, вручную — они лежат вне папки программы.

Программа работает в фоне — это безопасно?
Да. ChatClipper не выходит в интернет, не отправляет данные никуда и не читает ничего, кроме буфера обмена в момент копирования.
